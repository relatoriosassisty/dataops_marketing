# frontend local

interface react e vite com acesso direto ao gerador e ao enriquecimento. esta edição não possui autenticação ou campos comerciais.

para configurar e executar, consulte o [guia principal](../README.md). execute `npm test` para validar os fluxos locais e `npm run build` para gerar os arquivos estáticos.

as chamadas ficam em `src/services/`. o enriquecimento envia um arquivo multipart e recebe um xlsx; a geração de listas utiliza o identificador temporário retornado pelo levantamento.
