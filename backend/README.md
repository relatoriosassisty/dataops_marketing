# backend local

api flask para consulta, localidades, enriquecimento e exportação. execute `python -m backend.run` a partir da raiz do repositório após configurar o mysql.

esta edição não registra rotas de autenticação ou administração de contas e não depende de tabelas de usuários ou de acompanhamento financeiro. os logs operacionais são locais.

consulte o [guia principal](../README.md) para instalação e os [testes](tests/test_local.py) para os contratos da edição local.
